# BundleSafe privacy policy

Last updated: 8 August 2026

BundleSafe processes Java `.properties` files locally inside the JetBrains IDE in
which it is installed.

BundleSafe does not:

- collect analytics or telemetry;
- transmit file names, file contents, project metadata, or usage information;
- use cookies, advertising identifiers, or tracking technologies;
- require an account; or
- contact a BundleSafe-operated server.

The plugin reads affected resource-bundle files to prepare a preview and writes
them only after the user confirms that preview. JetBrains Marketplace, the
installed JetBrains IDE, and GitHub may process information independently under
their own policies; that processing is not controlled by BundleSafe.

If BundleSafe later introduces any networked or diagnostic feature, this policy
and the plugin UI will be updated before that feature is enabled.

Privacy questions can be submitted through the
[BundleSafe issue tracker](https://github.com/altairRs/BundleSafe-Support/issues).
